# How-to Guides

Practical recipes for specific tasks. Unlike the [Tutorial](../tutorial/tutorial.md), which walks
through building a first model from scratch, these guides assume you already have a model and want
to accomplish something particular with it.

- [Model an amplifier](./model_an_amplifier.md)

    Turn a lens, wedge or cylindric lens into an amplifier and analyze the model at several pump
    conditions — in the graphical user interface and in code.
