# Build from Source

In order to build and use OPOSSUM you have to have installed the rust programming language on your system. For this, pease foloow the instructions on the offical rust-lang installlation page:
[https://www.rust-lang.org/tools/install](https://www.rust-lang.org/tools/install).

To get the latest, but potentially not stable version, clone the source code from the [OPOSSUM repository](https://github.com/opossum-labs/opossum/) or download the latest stable release from our [OPOSSUM release page](https://github.com/opossum-labs/opossum/releases).
