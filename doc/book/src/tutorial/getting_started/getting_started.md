# Getting Started

To use OPOSSUM, you can either download and install the latest Windows or Linux installer from our repository, or clone the repository and build it yourself.  

The following two sections will guide you through both approaches:
- [Building from source](./build_from_source.md)
- [Using an installer](./installation.md)

Not required, but recommended for optical-setup visualization in generated OPOSSUM reports, is the installation of [Graphviz](https://graphviz.org/download/)
