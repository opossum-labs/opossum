# Preface

This book serves as the documentation of the OPOSSUM project (**OP**en **S**ource **O**ptics **S**imulation **S**ystem and **U**nified **M**odeller).  
Its purpose is to provide a comprehensive overview of the internal structure of OPOSSUM, to explain its usage, to report on its current state of development, and to outline the long-term vision of the software.  

As OPOSSUM is an evolving project, this documentation is not intended to be a *finished* work. Instead, it will be continuously extended and refined in parallel with the ongoing progress of the project.
