OPOSSUM (**OP**en Source **O**ptics **S**imulation **S**ystem and **U**nified **M**odeller) is a platform for simulating and designing optical systems, with an emphasis on large-scale, high‑energy/intensity laser systems. This book is the project documentation for OPOSSUM.

## How to read this manual

This manual follows the Diátaxis framework and is organized into four complementary sections:

- **Concepts / Explanation** — Overview of OPOSSUM and its design principles. 
Start with the [introduction](./concepts/intro.md) and see [concepts](./concepts/concepts.md) for detailed explanations.  
- **Tutorials** — Step‑by‑step guides to install and use the software.
Begin with [installation](../tutorial/installation.md) and then follow the [tutorials](../tutorial/tutorial.md).  
- **How‑to Guides** — Practical recipes for accomplishing specific tasks (e.g., modeling a particular optical system).
See [How‑to Guides](../howto%20guides/howto%20guide.md).  
- **Reference** — Comprehensive, in‑depth documentation of the software.
See the [reference](../reference/reference.md).

Suggested reading order: Concepts (first chapters only) → Tutorials → How‑to Guides → Concepts (further chapters) → Reference.
